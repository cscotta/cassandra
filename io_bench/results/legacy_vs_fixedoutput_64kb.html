Reading the results — IOPS down, bytes up

Fixed-output cuts the device read count but raises the bytes per read. The two metrics move in opposite directions, and the reason is the same in both: fixed-output makes every read one aligned 64 KB block, whereas legacy reads a variable ~29 KB compressed chunk at an unaligned offset.

  • IOPS (device reads): fixed-output wins — −17% cold, −19% warm. Alignment turns legacy's straddled/multi-read chunk fetch into a single aligned block read.
  • Bytes moved: fixed-output loses — VFS +75–79%, device +10–23%. A 64 KB block is more than twice legacy's ~29 KB compressed chunk, so serving one 3.1 KB value over-fetches more. Bigger blocks also cache less densely for random reads (hit rate 60.4% vs 71.9%), so more misses reach disk, which is why warm device bytes and the latency tail are worse and throughput is ~9% lower.
  • On-disk: fixed-output wins (−2.2%), now that padding is fixed.

Why this happens at S = 64 KB, and where the byte win actually is. Fixed-output reduces device bytes only when the block size S is smaller than legacy's compressed chunk. At S = 64 KB the block is larger than legacy's ~29 KB chunk, so bytes go up even though the read is aligned. On the same dataset at S = 16 KB, fixed-output measured cold ~40 KB/req and warm ~11 KB/op device — roughly half to a third of legacy's bytes. That is where the project's device-byte goal is met; the cost there is on-disk size (small-chunk context loss), recoverable with a shared dictionary. So S is the dial: small S trades on-disk size for a large byte reduction; large S trades byte reduction for a small on-disk win.

Conclusion. With the packer fix, fixed-output at equal 64 KB context is smaller on disk than legacy (−2%) and issues fewer device reads per lookup (−17–19% IOPS), but it moves more bytes per read because a fixed 64 KB block over-fetches versus legacy's ~29 KB compressed chunk — so throughput and tail latency are worse at this S. S = 64 KB is the “on-disk-optimal, byte-neutral-to-worse” end of the curve; the device-byte win that motivates fixed-output lives at small S (16–32 KB), where an S-sweep + a dictionary for the ratio is the next step. Throughput/tail figures carry normal warm run-to-run variance; the structural bytes-per-op and reads-per-op differences are the robust signal.
